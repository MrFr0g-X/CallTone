# Rate Factual Accuracy

## Purpose

Evaluates whether the agent provided correct information about products, services,
policies, pricing, and procedures. Checks against company-provided factual context.

## Weight

25% of overall score

## Scoring Rubric

- 100 = All information provided was correct
- 75 = Mostly accurate, one minor inaccuracy
- 50 = Mix of correct and incorrect information
- 25 = Multiple significant inaccuracies
- 0 = Provided fundamentally wrong information
