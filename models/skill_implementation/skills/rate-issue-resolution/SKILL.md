# Rate Issue Resolution

## Purpose

Evaluates whether the customer's problem or question was actually resolved
by the end of the call.

## Weight

5% of overall score

## Scoring Rubric

- 100 = Issue fully resolved, customer confirmed satisfaction
- 75 = Issue likely resolved, reasonable steps taken
- 50 = Partial resolution, some aspects unresolved
- 25 = Issue mostly unresolved, minimal progress made
- 0 = Issue not addressed at all
