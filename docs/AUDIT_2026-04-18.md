## 2. UI routes — 16 pages

Source: `calltone-UI/src/App.tsx`.

### 2A. Real & in scope — KEEP
- `/login` Login (174 lines) — clean, real
- `/agent/dashboard` AgentDashboard (252) — real data via API
- `/qa/dashboard` QADashboard (271) — real
- `/qa/call/:callId` CallDetail (360) — transcript + QA report
- `/qa/upload` UploadCall (302) — drag-drop with progress
- `/admin/dashboard` AdminDashboard (213) — real KPIs
- `/admin/team` AdminTeam (597) — real RBAC management
- `/admin/settings` AdminSettings (359) — pipeline settings
- `/accept-invite` AcceptInvite (164) — invite flow
- `/not-authorized`, `/*` (NotAuthorized, NotFound) — utility

### 2B. AI slop / out-of-scope — REMOVE or REWRITE
- **`/` Landing (488 lines) — REMOVE / REWRITE.**
  Contains fake stats ("98% Accuracy Rate", "2M+ Calls Analyzed",
  "500+ Teams Using CallTone"), fake SaaS pricing tiers
  ($49 / $99 / Custom), generic marketing copy. This is a
  graduation project, not a SaaS startup. Replace with a thin
  redirect to `/login` or a 30-line project intro that names the
  team, supervisor, and links to the GitHub repo.
- **`/admin/clients` AdminClients (224 lines) — REMOVE.**
  Multi-tenant SaaS console with revenue / MRR / plans
  (starter/professional/enterprise) and statuses
  (active/trial/churned/suspended). CallTone is a single-deployment
  graduation demo — there are no clients, no MRR, no churn. Backed
  by a real endpoint (`/admin/clients`) but the data shape is
  marketing fiction.
- **`/admin/permissions` AdminPermissions (198 lines)** —
  needs read; if it duplicates AdminTeam role-management, fold into
  AdminTeam.
- **`/admin/activity` AdminActivity (87 lines)** —
  smaller; if it shows fake activity feed, remove. Likely safe to
  delete and reduce admin-nav noise.

### 2C. Legitimate but bloated — TRIM
- **`/qa/context` CompanyContext (538 lines).**
  This drives Script Compliance scoring (legitimate), but 538
  lines is excessive. Likely combines 3 tabs (companies / upload /
  tickets) where the tickets tab maps to the borderline endpoints
  in 1D. **Action item A-03:** split or remove the tickets tab,
  keep the companies + upload tabs.
